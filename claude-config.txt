# claude-config.txt — CORE profile
# Shared configuration for claude-bootstrap.sh and claude-reset.sh.
#
# This file is the CORE: the identity layer every Bionic machine gets.
# Membership test: removing an entry here would change what Bionic *is*
# for every user. Stack-, org-, or account-specific tooling lives in
# profile files layered on top:
#
#   ./claude-bootstrap.sh                                # core only
#   ./claude-bootstrap.sh claude-config.everything.txt   # core + full catalog
#
# Profiles are additive-only: they can add entries and override single-valued
# settings (env-var by key, statusline — last file wins) but never remove core
# entries. Exact-duplicate lines across files are deduped; installs are
# idempotent either way. claude-reset.sh accepts the same profile arguments.
#
# Format: type|name|source
#   marketplace   |  name
#   plugin        |  name  |  source
#   github-skill  |  name  |  owner/repo
#   github-skill-pack | name | owner/repo  (multi-skill repo, each subdir = skill)
#   local-skill   |  name              (directory under skills/)
#   local-command |  name              (file under commands/<name>.md)
#   global-memory |  filename
#   brew-dep      |  binary              (package = binary)
#   brew-dep      |  binary  |  package  (when binary ≠ package)
#   brew-cask     |  binary              (cask token = binary)
#   brew-cask     |  binary  |  cask     (Homebrew cask; binary it provides ≠ cask token)
#   npm-global    |  package
#   pnpm-store    |  package             (importable JS lib pre-warmed into the pnpm store; pulled per-project via `pnpm add`)
#   uv-tool       |  package |  binary   (Python CLI via uv tool install; binary defaults to package)
#   mcp-server    |  name   |  package  |  ENV_VAR1,ENV_VAR2  (optional: required env vars)
#   env-var       |  key    |  value
#   statusline    |  command
